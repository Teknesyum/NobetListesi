# NobetListesi

Duty-roster tools by Teknesyum.

## HemsireNobet

Portable Electron roster for an operating-room nursing team: one list, quota and request aware, no back-to-back shifts, month panel with carry-over, alternatives view. Runs from a USB stick, no install and no browser.

- Download `HemsireNobet-portable-<version>.zip` from the latest `hemsirenobet-v*` release, unzip, run `HemsireNobet.bat`.
- The version button in the title bar checks for updates; a new code package is downloaded from the releases, verified (sha512) and applied on restart. A broken package falls back to the bundled code automatically.
- Staff data and saved months live in `veri/` next to the app and are never touched by updates.

Sources: [`HemsireNobet/`](HemsireNobet).
