# Ameliyathane HemşireNöbet

Portable Electron duty roster: one list, 20 nurses, all in the operating room. Copy the folder (with `electron/`) to a USB stick and run `HemsireNobet.bat`; nothing is installed, no browser is used.

- `boot.js` — Electron entry; picks the newest healthy code package in `veri/kod/<ver>` (falls back to the files here after two failed starts) and loads its `cekirdek.js`.
- `cekirdek.js` / `preload.js` — frameless window, IPC; data in `veri/` next to the app. `guncelle.js` — update check and install (GitHub releases `hemsirenobet-v*`, sha512 verified).
- `arayuz.html`, `uygulama.js`, `app.css` — two main tabs (Liste Hazırlama, Ayarlar) with sub-tabs; month strip; list is built only by the Listeyi Oluştur button; green next-step outline; hold right Ctrl for help; left Alt + click links requests into either-or groups (`k.bag`); guide flow İstekler → Özel Talepler → Oluştur. Teknesyum UI shell in `teknesyum-ui/`.
- `motor.js` — roster engine (separate duty-count and pay-point targets (Fri 2, Sat 3, Sun 2), Thursday-then-weekend-free, history of past months, fewest-wishes-first priority, per-weekday balance, groups with same-day limits and together/apart rules, "at least N of a weekday" special requests, optional bounded request balance, required-requests mode, history closed gradually at about one duty a month, an explicit duty count is exact, long leave shrinks the share, Friday + Sunday package requests, day-type fairness with per-day reasons in `gunNeden`, duty handover "X covers Z of Y's duties" that moves the share, either-or request and avoid groups, per-rule importance `kural.onem` (Off · Low · Normal · High · Strict, `MEKANIK`) set in the Düşünme Kuralları tab; an Off rule is not reported). `tatil.js` — Turkish public holidays, computed for any year. `veri.js` — anonymized default staff.
- `scripts/kod-paketle.js` — refuses a BOM, mojibake or a wrong productName, then builds `dist/kod-<ver>.zip` and `dist/kod.json` for a release. `scripts/portable-paketle.js` builds the portable zip. Release: bump `package.json`, run both, `gh release create hemsirenobet-v<ver>` with the three files.
- Local update test: `NOBET_KOD_URL=http://127.0.0.1:<port>` serves `kod.json` + zip.
- Every control and feature, new ones included, gets a help entry (`YARDIM` list or `yd()` in `uygulama.js`); right-Ctrl help must never fall back to the tab text for it.
